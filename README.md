# Umbrix — public web property

Public website for **Umbrix Messenger** — end-to-end encrypted, Apple-native 1:1 messaging.

- **Live site:** https://umbrix.khassinx.com (EN) · https://umbrix.khassinx.com/es/ (ES)
- **Stack:** Jekyll on GitHub Pages, fronted by Cloudflare (DNS, TLS, security headers).
- **Locales:** English (default) + Español under `/es/`. The site — like our support — is offered in these two languages only.
- **Structure:** `legal/` (privacy, terms, transparency, government requests, availability, warrant canary, infrastructure providers) · `security/` (responsible disclosure) · `support/` · `contact/` · `.well-known/security.txt` (RFC 9116).
