Someone shared their
Umbrix contact

This link carries a person's public key so you can message them privately. If you have Umbrix installed, tapping the link opens the app, which shows you who it is and asks whether you want to add them.

Nothing on this page is sent anywhere — there is no script and no tracker here.

Don't have Umbrix yet?

Umbrix is still in development and not on the App Store yet — it is in a closed beta, so there is nothing to install from this page today. The invite will still work once you have the app: ask the person to send it again then, or scan their QR code in person.

What this link actually contains

A public key, not an account

Umbrix has no accounts, usernames or phone numbers. A person's identity IS a cryptographic key generated on their device, so sharing a contact means sharing that public key — the half that is meant to be public.

Nothing reaches us

We operate no servers, and this page has no analytics, no trackers and no scripts. The invite code rides in the part of the address that browsers never send to a server, so it stays on your device.

You still confirm

Opening a link never adds anyone by itself. Umbrix shows you who it is and you decide. You can also verify the contact in person before trusting it.
